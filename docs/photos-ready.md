# Photos ready for Shopify (2026-11-20)

The list to start uploading from in the next session. A piece is **ready** when its main photo exists in every metal it
is offered in, the owner has approved it, and the 2026-11-20 spot-cleaning pass has been applied (background spots,
shadow blotches).
How to upload: `photography/upload-checklist.md` (Latin file names, alt text = the metal option value, a picture per
metal group). Product titles: `docs/product-names.md`.

Photo folders: `Pictures/PicturesForWebFaceInstagram/pictures for the website/<NN piece>/<metal>/`. In each metal
folder: `01 основна снимка` (main), then `02 …` (another angle) and `03 на ръка / на шията / на китката / носена`
(worn), when they exist. Silver uses its own `сребро` folder (a copy of white gold).

  Upload the `.png`; ask the owner whether the `.1.jpg` copies can be removed.
- Spot-cleaning backups are in each piece's `чернови/преди петната 2 2026-11-20/<metal>/` (the files as they were before
  this pass).
